# Energy Demand Forecasting

A data science case study focused on forecasting hourly energy consumption.

## Project Overview

The objective is to develop a machine learning model for forecasting the total hourly energy consumption of the Toroslar region and evaluate its performance using historical consumption, calendar, and meteorological data.

## Approach
-Exploratory Data Analysis
-Data preprocessing
-Feature engineering
-Time-based feature extraction
-Machine learning modeling
-Model evaluation
-14-day hourly forecasting
## Technologies
-Python
-Pandas
-NumPy
-Scikit-learn
-Matplotlib
